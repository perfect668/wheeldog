# DynaDress 开发边界

本目录独立于 `../upstream/`；M0 只建立目录和接口分析，没有算法实现。

- `simulation/`：未来的场景/时钟适配与基线对照。
- `robots/`：未来的固定底盘 H1 双臂与夹爪适配。
- `human/`：未来的固定躯干、单侧 4 DoF 被动动力学上肢。
- `garments/`：复用上游 FEM 资产及接触配置，避免复制资产。
- `data/`：未来的时钟同步与状态/估计负载/真实测量来源分离。
- `configs/`：未来实验配置与资产引用。

空目录仅用于组织，不代表功能已经实现。下一阶段入口见 `../docs/M0_SOURCE_MAP.md`。
