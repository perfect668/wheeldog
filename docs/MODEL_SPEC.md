# EXP0 模型定义与数值规范

## 目的
通过最小、透明、可计算的模型，回答“静态最大力/当前余量相同但力变化速度、控制迟延或可达性不同，会不会出现不同的可恢复扰动边界？”
**这是概念验证，不是 H1 真机证据，更不是尚不存在的新颖性证明。**

## 1. 最小横向人体模型
选择固定单一足部支撑模式、近似恒定 CoM 高度的 LIPM；全程 SI 单位。
- 状态：`x_h = [x, v]`，x 为 CoM 沿侧向相对固定 CoP 参考位置的位移（m），v 为侧向速度（m/s）。
- 参数：`m`（kg）、`h`（m）、`g`（m/s²）、`omega=sqrt(g/h)`（1/s）、固定 `p_cop=0`；此阶段不允许无限自由选择足底压力中心。
- 动力学：`dx/dt = v; dv/dt = omega**2 * (x-p_cop) + (f_assist + d)/m`。
- `f_assist` 是**实际作用于人体的、已定义符号方向的侧向合力**，而非命令值。`d` 可用短时侧向外力，或以 Δv 直接施加于扰动起点。两种扰动不可混淆。
- 初始平衡 `x=0,v=0,f_assist=0`，从静立测试开始；持续竖向扶持与起身任务不在 EXP0 模型范围。
- 方法可选精确零阶保持离散化，或收敛检查后的数值积分；记录 `dt` 与数值误差。

## 2. 抽象辅助执行器
`u_k` 为期望侧向力（N），`f_k` 为实际侧向力（N），二者因控制器与执行器动态不同。
- 基本能力：`|f_k| <= F_max`；`|u_k| <= F_cmd_max`。
- 力变化率：`|f_{k+1}-f_k| <= R_f * dt`，如需滞后可用一阶系统 `df/dt=(u-f)/tau` 并按 `R_f` 限速；明确所用版本。
- 感知/执行总延时：整数 `n_delay` 个步长的命令队列。延时期间不能应用尚未得到的信息。
- 可选单向承载 `f_min`、`f_max`，不要默认所有接触允许拉推双向用力；首轮可用双向理想支撑，并标成理想化假设。
- **实验性 A/B 配置**：可把 F_max 匹配、R_f/tau/delay 不同用于验证现象；该差别由人为抽象条件设定，绝不声称是 H1 自然产生的姿态差异。

## 3. 恢复判据
- 全程状态约束 `|x| <= x_safe`（只针对模型约束，不是临床人体跌倒阈值）；`|f|<=F_max`；必要时约束 `|v|<=v_abs_max`。
- 终端要求 `|x_H|<=x_terminal` 和 `|v_H|<=v_terminal`，更严格时使用已验证终端可控不变集。
- 输出状态：`RECOVERABLE / INFEASIBLE / SOLVER_ERROR`。不可把数值求解异常当成恢复失败或成功而不标注。
- **Oracle 计算**：给定已知扰动后求解存在性（上界）。**Causal closed-loop**：扰动不可被提前知道，使用同样的感知延时和在线反馈规则。两个结果分开报告。
- “恢复成功”仅表示此模型、此扰动集合、此状态约束和此时域下成功，不是实际不会跌倒。

## 4. 第一轮比较
- `Static-force test`：相同 F_max、不同 R_f/tau/delay 的抽象辅助器，画出不同 Δv 的恢复边界。说明当前最大力相同不足以保证同样的短时恢复能力。
- `Nominal tracking MPC`：以 x、v 和动作成本为目标，不显式优化恢复余量。
- `Known-disturbance oracle`：在给定扰动和约束下计算存在可行控制序列；用于检查上界。
- 后续加入多扰动场景鲁棒 MPC。共同动作的**非预见性约束**是强制的：扰动被观测到之前，不允许场景分支各自采用不同动作。

## 5. 首轮必须带的单元测试
- 零扰动、零初值、零辅助：状态保持平衡（数值误差范围内）。
- 扰动左右反转，且模型约束对称时：输出应近似镜像。
- 放宽 F_max 或 R_f 不应使 oracle 的可恢复集合缩小（在同一模型、无其他代价作为硬性限制时）。
- 缩短时域、增加响应延迟通常不应提高 oracle 可恢复集合，发现例外需排查判据与数值错误。
- 所有采样必须满足力限幅、延迟、状态边界；求解失败需报告。
- 每个 CSV/NPZ 记录扰动参数、初始状态、模型参数、求解状态、是否满足恢复判据和种子。

## 6. 必须明确报告的局限
固定足接触、恒定 CoM 高度、无踝/髋/迈步策略、抽象水平接触力；不模型化人体上肢与扶手压力、H1 底盘抗倾覆、真实接触迟滞。这些将在后续阶段补齐。
