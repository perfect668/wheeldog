# Codex → 用户/ChatGPT 审阅交接规范

每个里程碑完成时输出以下模板，用户把内容和 git diff/commit 链接交给 ChatGPT：

## 1. 实施范围
- 本轮目标：
- 涉及的代码文件：
- Commit hash / branch：
- 运行环境和依赖版本：

## 2. 可复现命令
- 安装：
- 单元测试：
- 运行单个实验：
- 生成图表：

## 3. 实际结果
- 数据路径、配置路径、种子：
- 结果汇总（不要只贴图片）：
- 图表（标明概念/仿真/实物）：

## 4. 有关模型的假设
- 人体模型的具体方程、状态、输入和符号约定：
- 机器人/执行器能力限制的实际来源：
- 终端目标与全过程约束：
- Oracle vs Causal feedback 是否区别：

## 5. 可能存在的问题
- Solver failure / infeasible 的区分：
- 数值敏感性、计算耗时：
- 对比实验公平性：
- 当前不能声称的结论：

## 6. 请求 ChatGPT 审阅
请重点检查：数学公式是否与代码一致；单位/符号/坐标是否一致；实验是否有数据泄漏/预知未来扰动；恢复成功定义是否严谨；结论是否超出了模型证据；是否有更简单强基线。
