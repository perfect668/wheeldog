# H1 Recoverability 项目 — M1-C 正式开发任务

## 一、项目背景与当前进度

我们正在开展一项面向 IROS 2027 的机器人控制研究。

**暂定研究主题：**

*Recoverability-Aware Whole-Body Assistance for Mobile Dual-Arm Robots*

中文：面向轮式双臂机器人的可恢复性感知全身辅助控制。

### 1. 应用背景

研究平台为珞石逐星 H1 轮式双臂机器人。

最终 Demo 是机器人辅助行动能力受限的人员完成床边起身、站立和行走。机器人通过两只机械臂提供物理支撑，并通过移动底盘与人体保持协调运动。

但当前阶段不开发完整 Demo，而是研究一个更基础的控制问题：

**机器人当前能够满足人体辅助需求，并不意味着它在未来短时间内依然拥有足够的辅助与恢复能力。**

举例：

两种 H1 全身姿态都能将左右扶手保持在相同位置，也都能提供相近的当前辅助力。

但是当人体突然向左偏移时，其中一种姿态可能因为关节配置、运动限位和底盘位置，无法及时移动扶手或改变支撑力。

因此，我们希望研究：

**H1 的全身姿态如何影响它当前的施力能力与未来有限时间内的支撑调整能力？两者之间是否存在显著差异？**

### 2. 已完成工作

**M0 / EXP0：已完成**

建立了简化人体倒立摆模型和具有动态约束的辅助执行器。

实验表明：在最大辅助力相同的情况下，响应速度、延迟和力变化率限制能够改变有限时间恢复能力。

但这只是抽象模型中的现象。

**M1-A：已完成**

完成 H1 URDF、连杆、关节、惯量、碰撞模型和技术参数审计。

**M1-B：已完成**

完成 H1 双臂正运动学、雅可比、逆运动学和冗余配置搜索。

在左右扶手目标世界位姿保持不变的条件下，48 次 IK 尝试中有 42 组达到条件性几何验收要求。

当前开发分支：

`m1/asset-kinematics`

本轮工作应基于现有 M1 源码，保留已通过验证的运动学和碰撞模块。

本轮启动：

**M1-C：H1 姿态相关的施力能力与有限时间支撑可达性分析。**

## 三、统一 H1 模型参数

以下参数由研究负责人确定，作为 M1-C 的主实验配置。

所有参数通过独立配置文件覆盖，不直接修改原始 URDF。

### 3.1 运动学参数

连杆尺寸、安装位置、关节坐标变换和旋转轴方向全部采用原始 URDF。

第 7 轴：

- 旋转轴采用 URDF 的局部 X 轴。
- 位置限位采用 ±90°，即 ±π/2 rad。

其余机械臂关节位置限位采用手册值，依次为：

1. 关节 1：±178°
2. 关节 2：±120°
3. 关节 3：±178°
4. 关节 4：−60°～145°
5. 关节 5：±178°
6. 关节 6：±60°
7. 关节 7：±90°

注意左右机械臂的具体关节名称和序号应根据已审计的 URDF 映射，不要仅凭字符串排序假设对应关系。

### 3.2 机械臂关节力矩限值

每侧七个关节：

```python
torque_limits_nm = [
    182, 182, 134, 134, 35, 35, 35
]
```

左右机械臂使用同一组参数。

将这些值作为当前研究配置中的名义力矩预算上限。实际可持续输出、短时峰值能力以及控制器是否允许使用全部预算，本阶段暂不做未经验证的假设。

### 3.3 机械臂最大关节速度

每侧七个关节：

```python
velocity_limits_deg_s = [
    175, 175, 270, 300, 240, 240, 240
]
```

计算时转换为 rad/s。

### 3.4 整机质量

采用手册值：

```python
robot_total_mass_kg = 190.0
```

原始 URDF 声明质量总和约 740 kg，存在明显异常。

不得直接使用原始异常质量建立整机稳定性结论。

本轮不要求完整重建每个零件的真实质量和惯量。若涉及重力补偿，允许采用参数化假设，但必须与纯运动学、纯力矩预算结果分开。

### 3.5 移动底盘

- 类型：四组舵轮，全向平面运动。
- 平面自由度：x、y、yaw。
- 最大平移速度：1.5 m/s。

底盘最大角速度、加速度、轮地摩擦和驱动力限制尚未完整确定。

允许采用明确标注的假设参数进行敏感性实验。

先采用运动学层面的 SE(2) 底盘模型，不要求立即实现四个轮组的精细动力学。

### 3.6 额外实验参数

为了研究有限时间能力，请将下列参数设计为可配置变量：

- 机械臂最大关节加速度。
- 底盘最大平移加速度。
- 底盘最大角速度与角加速度。
- 控制响应延迟。
- 控制周期。
- 有限时间预测窗口。

这些参数不应被标注为厂家实测值。

建议先选择合理的低、中、高三档条件进行敏感性分析，避免因为未知参数而停止研究。

## 四、任务 A：建立双臂辅助施力能力模型

### 目标

计算不同 H1 姿态下，两只机械臂能够向人体提供哪些方向、哪些大小的辅助力。

### 4.1 数学基础

利用现有雅可比矩阵：

\[
\tau_{\mathrm{contact}}=J_c(q)^Tf
\]

其中：

- \(q\)：机器人关节配置。
- \(J_c\)：扶手接触位置的雅可比矩阵。
- \(f\)：左右扶手接触力。
- \(\tau_{\mathrm{contact}}\)：接触力引起的关节力矩。

请统一机器人对人体施力与人体对机器人反作用力的符号定义。

在名义关节力矩预算下，建立满足关节力矩限制的辅助力可行集合。

注意：如果左、右机械臂共享上游躯干关节，应当累加两侧接触力对共享关节产生的力矩贡献，不能完全独立计算。

### 4.2 先做哪些分析？

优先分析：

- 左右方向辅助力。
- 前后方向辅助力。
- 竖直方向支撑力。
- 双臂同时施力时的联合可行性。

对于不同机器人姿态，计算各方向的最大可行辅助力，以及完成同一个给定扶持任务后剩余的力能力裕度。

先使用静态关节力矩预算模型建立清晰的基准结果。

随后如有可靠的质量模型，再加入重力补偿项。

### 4.3 需要输出什么？

每组机器人配置应记录：

- 机器人关节配置和底盘位姿。
- 左右扶手位置与姿态。
- 当前辅助力能力。
- 任务辅助力下的剩余能力。
- 主要限制关节。
- 约束来源与参数假设。

还需要生成不同配置的辅助施力能力对比图。

## 五、任务 B：计算有限时间内的扶手运动可达性

### 目标

研究当前扶手位置相同的情况下，不同机器人配置在短时间内可以怎样调整扶手。

重点关注：

**0.2 秒、0.3 秒和 0.5 秒内，H1 能否及时将左右扶手移动到新的支撑位置。**

### 5.1 第一阶段：瞬时运动能力

利用：

\[
\dot x=J(q)\dot q
\]

及关节速度限制，分析当前姿态沿不同方向的末端运动能力。

至少输出：

- 左右方向最大瞬时速度。
- 前后方向最大瞬时速度。
- 竖直方向最大瞬时速度。
- 双臂共同调整时的可行运动方向。

同时记录接近限位或雅可比退化对结果的影响。

### 5.2 第二阶段：有限时间可达性

不能简单将最大瞬时速度乘以 0.3 秒后当作最终答案。

需要使用多步运动学计算，在运动过程中持续更新机器人姿态、雅可比及限制条件。

考虑：

- 关节速度限制。
- 关节加速度假设。
- 关节位置限位。
- 左右扶手协同约束。
- 机器人自碰撞。
- 底盘平面运动限制。

初期可以采用离散时间运动学优化或连续小步规划。

不必立即实现复杂全身动力学求解器。

建议先实现固定底盘版本，再实现底盘可以移动的版本，以便观察全身冗余性带来的收益。

### 5.3 接触条件

当前扶手使用法兰坐标系的虚拟接触点。

请添加可配置的 `handle_frame`，允许指定法兰到实际扶手接触点的刚性变换。

初始默认可使用单位变换，保持与 M1-B 的数据一致。

在有限时间可达性测试中，请明确当前采用的双扶手协同约束。例如：

- 两只扶手同步平移。
- 两只扶手维持相对位姿。
- 左右扶手分别进行有限幅度调整。

优先采用符合双臂共同辅助人体的协同运动条件，避免单侧机械臂任意移动而脱离接触任务。

### 5.4 输出指标

对每个预测窗口输出：

- 最大可行左右位移。
- 最大可行前后位移。
- 最大可行竖直位移。
- 双臂共同运动能力。
- 运动过程中的限制因素。
- 求解成功率和计算时间。

## 六、任务 C：寻找具有研究价值的配置对

这是本轮最重要的任务。

### 6.1 配置对必须满足什么条件？

对于机器人配置 A 和 B：

**条件 1：当前任务相同。**

左右扶手的世界位姿应当相同，误差处于统一的 IK 验收阈值内。

**条件 2：当前施力能力相近。**

优先匹配目标方向或规定任务力集合上的施力裕度。

初期可以采用约 5%–10% 的匹配容差作为筛选参数，具体根据实际配置分布调整并记录。

不要仅比较一个任意方向上的最大施力数值。

**条件 3：有限时间可达能力存在差异。**

例如在 0.3 秒内，配置 A 和 B 向左调整双扶手的最大可行位移不同。

也要检查右侧、前后方向，避免只挑选单一有利场景。

### 6.2 配置搜索方式

先利用 M1-B 已有的 42 组条件性合格 IK 配置。

必要时扩大 IK 搜索范围，增加底盘位置和关节冗余采样。

但不要以“生成尽可能多的 IK 解”为目标。

重点寻找**当前辅助任务表现接近，但未来运动能力不同**的配置。

所有差异应当来自机器人配置与统一约束，而不是人为给 A、B 设置不同执行器响应参数。

### 6.3 关键研究问题

请通过实际数据回答：

1. 是否存在当前施力能力相近，但短时运动可达性显著不同的 H1 配置？
2. 差异主要来自哪些关节、冗余姿态或底盘位置？
3. 仅根据当前施力能力，能否判断哪个配置未来更有利？
4. 允许底盘参与运动后，配置之间的差异会扩大还是缩小？
5. 哪些方向的恢复能力更依赖全身配置？

如果结果并不支持研究假设，请如实报告，不要人为制造显著差异。

## 十、本轮研究的最终验收标准

本轮不是以代码量、图表数量或优化器复杂度衡量完成度。

**最重要的验收问题是：**

> H1 是否真实存在某些全身配置，它们完成当前辅助任务的能力相近，但面对未来快速支撑调整需求时，表现出明显不同的运动与施力能力？

我们需要真实的机器人运动学数据支持这个判断。

如果发现这种差异：

请进一步解释差异产生的物理原因，并为 M1-D 人体—机器人联合恢复实验准备合适的典型配置与能力约束数据。

如果没有发现：

请分析现有配置范围、任务选择和评价指标是否足以揭示这一现象，提出基于实际结果的下一步研究建议。

不要为了支持预设结论而人为修改机器人参数或筛选实验。

**本轮完成后停止，不提前启动 M1-D，也不开发新的预测控制策略。**

我们的科研原则是：

**现象 → 问题 → 原因 → 矛盾 → 洞察 → 方法 → 实验。**

当前 M1-C 的任务，就是通过 H1 的真实运动学结构，找到足以支撑后续方法设计的物理现象。

最终目的是建立一套真正有价值的未来辅助能力评价与控制方法，而不只是完成一个双臂机器人性能测试程序。
