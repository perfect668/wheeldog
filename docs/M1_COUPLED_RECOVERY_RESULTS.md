# M1-D：人体—H1 联合有限时间恢复实验

2026-11-12；分支 `m1/coupled-recovery`；基线 `c546434dbb8f15569812e06ecb853705307388f4`。

## 对科学问题的回答

**在本轮明确的接触模型、名义约束和相同求解程序下，不同初始配置产生了不同的人体模型恢复结果；但路径搜索和保守包络显著影响差异，尚不能认定这是与搜索器无关的机器人固有恢复能力排序。** 更不能据此声称真实H1或真实人体的恢复能力差异。

主曲线法在固定底盘、1.6s窗口下，`ik0024/ik0036` 的双向离线局部转变括号分别为0.030–0.035与0.200–0.205m/s。但独立关节轨迹优化可让同一个`ik0024`恢复−0.1854m/s，主曲线法在**该精确幅值**下仍不可行。因此不能把主曲线的不可行当作人体—H1的全局不可恢复。

独立优化修正版中，`ik0036`也找到更大的已验幅值，且两配置都出现方向性。现有证据支持继续研究耦合恢复，优先解决路径类和数值保守性；未获得全局边界、算法创新或强基线优势证据。本轮完成后停止，等待审阅。

## 接触模型与公平比较

世界+Y横向。人体质量70kg、高度1m、g=9.81m/s²、固定CoP，无自主踝/髋/迈步。每手初始竖直支撑30N、水平0N；虚拟人体双手随质心平移，等效合力作用于质心，不额外建模人体滚转。

\[
f_i=250(y_i-x)+15(\dot y_i-\dot x)\quad[\mathrm N],\qquad
\ddot x=(9.81-60/70)x+(f_L+f_R+d)/70.
\]

刚度单位N/m，阻尼N·s/m；向上60N对腿部法向力的影响显式进入LIPM。接触能量/耗散恒等式及独立ODE验证通过。力由实际相对位置/速度产生，**没有把扶手最大位移映射成最大辅助力**。

每手合力上限80N，对应水平硬上限±74.161985N。初始四配置在相同30N竖直载荷下，计入共享躯干预算后的可用水平区间均恰为上述接触区间；最大初始接触补偿预算比为0.453–0.493，见`initial_tasks.json`。
这表示本模型的共同接触上限在限制当前任务，不是厂家确认的H1施力能力。

名义臂预算沿用M1-C；四个共享躯干关节各100Nm，左右负载**相加**。统一假设臂加速度15rad/s²、SE(2)底盘加速度1.5m/s²、yaw速度0.6rad/s与加速度1.5rad/s²、动作延迟40ms。关节范围/速度和轴向覆盖沿用M1-C，不改URDF原文件。接触点为现有法兰handle_frame，无实体扶手模型。

相同人体、接触、初始支撑任务、扰动、求解器、延迟与运动参数施加于全部配置。`ik0024/ik0036`初始底盘不同；`ik0001/ik0010`初始底盘同为零，作为补充。固定底盘时只动14臂关节；移动曲线增加SE(2)，躯干位置冻结但仍承担接触负载。所有动态/接触参数为未标定研究假设。

|---|---:|---:|---:|

## 约束、接触与敏感性解释

主固定空间曲线在ik0024负向约−0.020m处续接失败，近折返使D1/D2放大；即使仅±0.01m域，充分速度/加速度也只有约0.0741m/s、0.8915m/s²。ik0036同域约0.4785m/s、3.2670m/s²。
这些是所选曲线的保守界，**不是H1最大末端速度或真实加速度**。直接关节法可以选择其他冗余运动，并使用完整假设关节加速度；修正版最佳轨迹均达到关节加速度比1，而主已验轨迹最高约0.718。大幅改变量级主要支持几何路径与运动约束保守性的解释。

单因素敏感性在主对、固定底盘、H=1.6s、四扰动±0.16/±0.24m/s上运行。下表为ik0036的成功数/4；ik0024在这些较大扰动上均为0/4，不能据此说明它对参数不敏感。

| 变化（其余保持相同） | 离线 | 因果 |
|---|---:|---:|
| 名义设置 | 2 | 2 |
| 躯干60或200Nm | 各2 | 各2 |
| 每手合力上限50或120N | 各2 | 各2 |
| k=150 / 400 N/m | 0 / 4 | 0 / 2 |
| c=5 / 30 N·s/m | 2 / 2 | 0 / 2 |
| 臂加速度5 / 30 rad/s² | 0 / 4 | 0 / 2 |
| 延迟0 / 80ms | 2 / 2 | 2 / 0 |
| 控制步长20ms | 2 | 2 |

这只是四点敏感性，不是每个变体的精细边界。未变的计数不能排除边界内小变化。
在该样本中，接触刚度、关节加速度、反馈阻尼/延迟更显著；没有发现扩大躯干/接触力预算提高这四点成功数的证据。
独立修正版ik0036/−Y则已接近接触上限（比约0.993），说明扩大搜索类后限制因素可能改变，不能一概说力上限不重要。
静止扶手基线24案例（k=150/250/400、相同扰动与接触）无一在1.6s满足终端条件，见`passive.json`。

M1-C的位移/速度指标缺少接触刚度、阻尼、人体状态演化、力的方向/时序和反馈信息，不能直接成为恢复指标。本轮已补这些耦合，但仍缺少真实机器人惯性/载荷响应和真实人体接触模型。

## 数值、失败与终端限制

自动测试**70项全部通过**；原M0/M1/M1-C的48/26/4519项冻结SHA均匹配。
详细误差和故障注入见 [M1_COUPLED_TEST_REPORT.md](M1_COUPLED_TEST_REPORT.md)、`validation.json`。
399条主求解器接受轨迹的最大独立人体ODE差约2.84e-8m与3.31e-8m/s；最大动力学残差约7.96e-14。直接关节法的较大线性化误差另行报告，未混用这些数字。

**“恢复成功”只指在指定H内返回接受条件。** 人体终端箱不是已证明的可控不变集，重放是模型内一致性检查。
`recovery_time_s`另要求进入人体/扶手箱并保持到记录结束至少0.20s；399条主方法成功中269条不满足这一持续停留判据，该字段为null，不能宣称持续站稳。
`settling_times.csv`另存首次进入且留到记录结束的时刻与实际观测停留时长，避免用H冒充已验证的恢复时间。
例如ik0036/+0.16m/s两种主控制都只在最后节点满足全部人体与扶手箱，记录停留时长为0；直接修正版最佳轨迹也只有0–5ms箱内观测。没有作终端后持续稳定实验。

本机阶段墙钟约：prepare42s、主扫描118s、敏感性167s、未来事件9s、串行局部细化392s；独立v1每案例86–110s，修正版双CPU worker每案例94–99s。1135主案例的累计逐案墙钟1489.9s、中位1.005s、最大9.258s；并行累计量不能当实际总运行时长。
mesh为有限采样且部分开口，无人体/地面mesh。预算只约束接触补偿力矩，不含机器人重力/加速惯性、驱动带宽、底盘轮地力/摩擦/倾覆和真实控制误差。不能作硬件可执行性、连续碰撞或人体安全证明。

## 审阅交接与下一步最小问题

请优先审阅：竖直载荷等效和手随CoM假设是否合理；被动接触力与延迟是否一致；离线/因果信息是否真正隔离；两种终端接受与持续停留定义是否清晰；路径类不可行是否被过度解读；直接优化的中点约束、非线性重放和较大线性化误差是否足够。

证据等级：条件化人体模型差异已有数据；搜索器影响已有精确幅值反例；真实H1动态施力/人体恢复、全局配置排序和新算法优势均未验证。
建议审阅后的最小任务是构造包含固定/移动路径的联合类、在相同精确扰动上作更充分的冗余搜索，并明确持续终端要求，再决定是否需要新的预测优化算法。本轮不执行这些后续工作。
真实机器人阶段仍需厂家确认驱动/躯干预算、轴向及底盘约束，并标定接触和加载响应；这些信息不影响本轮按假设模型交付，不能用假值补成厂家结论。
