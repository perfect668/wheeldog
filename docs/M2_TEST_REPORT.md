## 实际实验与保存数据复算

- 正式评分：16个方向案例 × 3初值 × 24迭代 = 1152个子问题，全部返回 `LINEARIZED_OPTIMUM`，全部通过主重放。48个初值中8个为退回零种子的重复，记录在各 `score_cases/*.json:seeds`。
- 正式闭环：768次，283次完整，485次提前停止。150次主终端成功，150次保持额外0.8 s；其余失败/未达终端条件完整保留。
- 在线QP：13405次调用，11373次solved、1861次达到迭代上限、171次solved inaccurate；2032次回退。后两类均未作为求解成功使用。达到迭代上限不能记作已证不可行。
- `audit.json` 复算所有768条的判定、实际人体范围、实际接触力与力矩、关节位置/速度/加速度、固定底盘和延迟队列：**0差异**。这里验证的是已记录前缀，提前停止仍是失败。
- 最大实际环境与独立重放人体状态差 `1.139e−13`（m / m/s）；最大扶手位置误差 `3.524e−8 m`、角度误差 `2.077e−8 rad`；候选初始扶手位置差 `3.545e−10 m`。
- 2.5 ms / mesh 10 ms加密重放：16条最佳评分轨迹全部通过；16条闭环轨迹全部通过记录段检查，其中8条完整主恢复轨迹覆盖持续观察窗，8条为较强扰动的失败前缀。完整与截断在JSON中明确区分。
- PNG图表已作视觉检查；敏感性图使用同样四个名义扰动作匹配比较，强/轻扰动轨迹均保留、没有在失败后填补曲线。
- 独立保存的36次固定参数复跑：36/36主判定一致、轨迹长度一致、fallback次数一致，节点状态和送达控制最大差均为0。见 `results/m2a/repeatability/summary.json`；这是原场景数值复核，不是额外独立方法测试。
